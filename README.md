# 2030 NS · Chicken & Beer

Улаанбаатар хотын **2030 NS Chicken & Beer** — солонгос загварын шарсан тахиа ба
шар айрагны landing page. Утас + компьютерт зохицсон (responsive), онлайн сагстай.

## Агуулга

- `index.html` — Үндсэн сайт (бие даасан, гадны framework-гүй). CSS + JS дотор нь.
- `img/` — Хоолны зургууд (эх постеруудаас тайрсан): `fried, garlic, gold, cheese,
  yangnyum, side, hero`.

## Онцлогууд

- Hero, marquee, "Яагаад 2030?" онцлогууд, бүтэн цэс (Fried / Garlic / Gold /
  Cheese / Yangnyum · 43K / Side), таб солигддог
- **Онлайн сагс** — нэмэх/хасах, нийт дүн, захиалга баталгаажуулах урсгал
- Захиалга & Хүргэлт, Бидний тухай, Сэтгэгдэл, Байршил (Facebook холбосон)
- Scroll reveal, hover, marquee хөдөлгөөн
- Фонт: Unbounded + Golos Text (онлайн үед ачаалагдана)
